\begin{abstract}
This thesis studies \emph{control} in visual systems. A model is controllable if its output follows the specification it is given. Visual understanding and visual generation differ in what that specification is, but they fail to follow it in the same way.

In visual understanding, a useful scene description must report interactions rather than object categories alone. Detecting a person and a horse is considerably less informative than predicting that the person is \textit{riding} the horse. Relation prediction is therefore the mechanism through which a scene becomes queryable. Because a small number of generic predicates dominate existing annotations, current models predict \textit{on} where \textit{riding} is correct, and the informative relation is never produced. In visual generation, the requirement is supplied directly. Given one or more reference images of a garment, an object, or a person, the model must synthesize an image or a video in which that subject is reproduced faithfully. Current models generate plausible output but fail to preserve identifying detail: logos and texture patterns are distorted in generated images, and subject identity drifts across frames in generated videos.

Neither failure arises from missing information. The rare predicate lies within the label space of the first model, and the subject to be preserved lies within the reference images of the second. What is absent is a training signal that favors the intended prediction over the more easily obtained one. The central claim of this thesis is therefore that control must be trained into a model rather than supplied to it. The intended behavior must be attached to an explicit quantity and supervised directly. In visual understanding this quantity is a subject--object--relation triplet grounded in panoptic masks. In visual generation it is human pose, the spatial correspondence between a reference image and the output, and the consistency of a subject across the frames of a video.

To study control in visual understanding, this thesis adopts panoptic scene graph generation (PSG). PSG segments an image into panoptic entities and predicts subject--object--relation triplets, forming a pixel-grounded scene graph over both ``things'' and ``stuff'' categories. PSG requires accurate localization, interaction modeling, and semantic generalization, and it makes explicit the relations over which control is exercised. Chapters~3--5 progressively widen this control. \emph{HiLo} introduces frequency-specialized branches for high- and low-frequency predicates and enforces cross-branch consistency, which recovers rare relations under semantic overlap without sacrificing frequent ones. \emph{VLPrompt} augments relation prediction with context-rich language cues elicited from large language models (LLMs), and learns when those cues should be trusted, which improves prediction for rare and ambiguous predicates. \emph{OpenPSG} pairs open-set panoptic segmentation with efficient pair filtering and autoregressive multimodal relation decoding. The relation vocabulary then moves from a fixed classifier head to a specification supplied at inference time.

To study control in visual generation, this thesis addresses reference-conditioned synthesis, in which the output must reproduce a subject specified by one or more reference images. Chapters~6--7 treat this requirement as an explicit learning objective rather than as an additional input. \emph{Leffa} introduces an attention regularization loss that interprets the cross-attention map as a soft correspondence field and supervises it during training. This directs reference-conditioned diffusion models to the correct source regions and reduces detail distortion in virtual try-on and pose transfer. \emph{Saber} extends the same requirement to the temporal domain. It learns from ordinary video--text pairs through masked training and attention design, preserving identity across frames without expensive reference image--video--text triplets.

The five chapters follow a common pattern. In each, the model is provided with the information required to satisfy the specification: a label space containing rare predicates, a set of language descriptions, an open relation vocabulary, a reference image, or a set of reference frames. In each, it defaults instead to the frequent predicate, the salient reference region, or the neighboring video frame. In every case the intended behavior is recovered once it is made an explicit training target. Wider control over what a system reports about a scene, and more reliable control over what a system generates, are two instances of the same result. Control is a property that a model is trained to possess, not one that follows from providing additional inputs.
\end{abstract}
